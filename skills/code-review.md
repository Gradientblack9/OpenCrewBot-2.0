# Code Review

Use read-only inspection to cite files or upstream issues. Identify maintainability, correctness and test gaps. Prioritize a small set of proposed improvements with acceptance checks. Keep findings defensive and flag assumptions when evidence is incomplete.

Use the actual identifiers and control flow shown in the source. A source excerpt alone cannot establish whether a symbol is unused or an entire repository has no tests. Distinguish what you found in the reviewed files from a proposal for additional coverage.
